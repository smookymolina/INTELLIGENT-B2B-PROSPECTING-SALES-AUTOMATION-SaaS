# Riesgos y mitigaciones

| Riesgo | Mitigación |
|---|---|
| contacto no permitido | supresión, evidencia, revisión legal y límites |
| fuga multitenant | RLS, tests, auditoría |
| coste IA/datos | cuotas, ledger, caché segura, modelos por tarea |
| proveedor falla/cambia | adaptadores, contratos, fallback |
| clasificación errónea | umbrales, evidencia y humano |
| entregabilidad/cuenta bloqueada | políticas, consentimiento, ritmo y monitoreo |
