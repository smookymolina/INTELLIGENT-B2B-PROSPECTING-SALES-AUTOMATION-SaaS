**Proyecto:** Intelligent B2B Prospecting & Sales Automation Platform  
**Responsable del proyecto:** Jair Molina Arce  
**Entorno:** VS Code + GitHub  
**Agentes principales:** Claude Code + OpenAI Codex  
**Metodología:** Multi-Agent Engineering + Documentation-Driven Development

---

# 1. TU MISIÓN

Actúa como CTO, Principal Software Architect, Senior Full-Stack Engineer, AI Engineer y Technical Product Manager.

Serás responsable de establecer las bases de ingeniería de un producto SaaS profesional, escalable, multiempresa y comercialmente viable.

Trabajarás con dos agentes de inteligencia artificial:

- Claude Code (Anthropic).
- OpenAI Codex (OpenAI).

Ambos deben colaborar como un equipo de ingeniería coordinado, aprovechando sus capacidades para reducir tiempos de desarrollo, mejorar la calidad y distribuir las tareas de forma inteligente.

No quiero un prototipo improvisado, una aplicación de demostración ni un conjunto de scripts desconectados.

Quiero construir un producto SaaS real, preparado para comercializarse a diferentes empresas, sectores e industrias.

**Tu objetivo es crear un sistema que transforme información empresarial en oportunidades comerciales reales, automatizando la prospección, el contacto inicial, la identificación de interés y la transferencia de leads al departamento de ventas.**

No prometas conversiones absolutas. Diseña una plataforma medible, optimizable y orientada a maximizar la generación de oportunidades comerciales calificadas.

# 2. VISIÓN GENERAL DEL SOFTWARE

Desarrollaremos una plataforma SaaS que permita a cualquier empresa encontrar nuevos clientes dentro de zonas geográficas específicas y automatizar su proceso inicial de prospección comercial.

El sistema debe funcionar para diferentes tipos de negocios sin necesidad de modificar su código fuente.

Ejemplos de posibles clientes del SaaS:

- Empresas de compresores industriales.
- Distribuidores de maquinaria.
- Proveedores de equipos industriales.
- Empresas de seguridad.
- Distribuidores de materiales.
- Empresas de servicios B2B.
- Proveedores de mantenimiento.
- Empresas comerciales de diferentes sectores.

Cada empresa configurará su propio perfil, catálogo, mercado objetivo, zonas geográficas, canales de comunicación y equipo comercial.

## Flujo comercial principal

1. La empresa registra su negocio.
2. Configura productos y servicios.
3. Define su cliente ideal (ICP).
4. Selecciona zonas geográficas.
5. El sistema busca empresas potenciales.
6. Enriquece y valida sus datos comerciales.
7. La IA analiza su compatibilidad.
8. El usuario selecciona los prospectos.
9. Se diseñan campañas de correo y WhatsApp.
10. Se ejecutan secuencias de contacto autorizadas.
11. El sistema recibe e interpreta respuestas.
12. Identifica interés comercial.
13. Genera automáticamente un LEAD cuando corresponde.
14. Asigna el lead al vendedor adecuado.
15. El vendedor continúa la conversación.
16. El vendedor prepara cotizaciones y negocia.
17. Se registra el cierre o pérdida de la oportunidad.
18. El sistema analiza resultados y optimiza futuras campañas.

El sistema debe permitir rastrear el recorrido completo desde la fuente del prospecto hasta la venta final.

## M06 — Lead Scoring

- Coincidencia con ICP.

- Ubicación.
- Tamaño estimado.
- Necesidad identificada.
- Calidad de información.
- Disponibilidad de contacto.
- Historial comercial.

Clasificación:

- 80–100: prioridad alta.
- 60–79: prioridad media.
- 40–59: prioridad baja.
- 0–39: no prioritario.

El resultado debe ser explicable y no debe confundirse con intención de compra confirmada.
