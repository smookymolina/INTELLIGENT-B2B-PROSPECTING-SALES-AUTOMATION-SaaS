# Protocolo de integración

PR contiene propósito, decisiones, pruebas, riesgos, migración/rollback y docs afectadas. Revisor comprueba tenant/RBAC, validación, idempotencia, secretos/PII, observabilidad y compatibilidad. Rebase/merge sólo tras checks; actualizar changelog y estado. No hay Git aún: crear repositorio es tarea de Fase 1 autorizada.
