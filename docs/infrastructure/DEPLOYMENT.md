# Despliegue

Entornos aislados dev/staging/producción; imágenes inmutables, migraciones controladas, configuración externa y secretos gestionados. API y worker escalan por separado; health/readiness, backups y rollback probado. CI: lint/test/build/escaneo; CD requiere aprobación. Definir RTO/RPO, región, proveedor y runbooks antes de producción.
