# Criterios transversales

Una historia se acepta si: alcance y actor claros; autorización/RLS; validación y errores; auditoría/evidencia; telemetría; pruebas automatizadas; documentación/contratos actualizados; límites/coste evaluados; UX accesible mínima. Un módulo no se declara terminado sin evidencia reproducible de sus criterios particulares.
