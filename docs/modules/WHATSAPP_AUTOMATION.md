# M09 WhatsApp
Objetivo: mensajería sólo por Meta Cloud API. Entidades: WhatsAppAccount, Template, Conversation, Message, WebhookEvent. Reglas: consentimiento, plantillas aprobadas, ventana aplicable y opt-out; sin automatización no oficial. Fallos/ambigüedad pasan a revisión. Aceptación: firma webhook, idempotencia, estado de plantilla y transferencia a humano.
