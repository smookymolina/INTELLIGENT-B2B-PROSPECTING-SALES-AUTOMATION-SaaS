# M14 Analítica
Objetivo: métricas accionables y atribuibles. Fuente: eventos de negocio, no inferencias de UI. Entidades: MetricDefinition, FactEvent, Dashboard. Reglas: timezone/ventana definidas, filtros tenant, datos tardíos y deduplicación; distinguir etapas del embudo. Aceptación: definición visible, drill-down a eventos y conciliación con transacciones.
