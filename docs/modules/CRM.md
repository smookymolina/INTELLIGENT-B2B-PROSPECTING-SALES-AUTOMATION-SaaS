# M12 CRM
Objetivo: gestionar pipeline y actividad comercial. Entidades: Lead, Opportunity, StageHistory, Task, Note, Activity, LossReason. Etapas: nuevo, pendiente, contactado, calificación, cotización solicitada/enviada, negociación, ganado, perdido, futuro. Reglas: transiciones válidas, historial inmutable y permisos por rol. Aceptación: kanban filtrado por tenant, timeline y SLA.
