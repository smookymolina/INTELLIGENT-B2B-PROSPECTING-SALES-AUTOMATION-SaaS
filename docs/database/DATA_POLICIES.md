# Políticas de datos

Clasificar: cuenta, comercial, contacto, conversación, integración y auditoría. Minimización y finalidad antes de capturar; origen, permiso/preferencia, validación y retención por atributo. Bajas/supresión prevalecen sobre campañas. Retención, derechos de titulares, encargados, transferencias y eliminación segura requieren aprobación legal antes de producción. Backups cifrados, restauración probada y borrado propagado conforme a política.
