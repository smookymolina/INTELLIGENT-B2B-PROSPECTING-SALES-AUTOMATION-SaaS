# Arquitectura de seguridad

Defensa en capas: IdP/contraseñas seguras y MFA futura, sesión corta, RBAC, RLS, validación DTO, rate-limit, CORS/CSRF según canal, cifrado TLS/en reposo, gestor de secretos, SAST/dependencias, logs auditables y alertas. Amenazas prioritarias: fuga intertenant, webhook falsificado, abuso de campaña, prompt injection, exfiltración de PII y secretos. Incidentes: detectar, contener, preservar evidencia, comunicar y corregir.
