# Integraciones

Contratos de adaptador: `discover`, `enrich`, `send`, `receive`, `classify`, `generate`; respuestas normalizadas incluyen proveedor, versión, coste, estado y evidencia. Configuración por tenant cifrada y con capability flags. Sólo APIs autorizadas: Google Places/OSM/directorios permitidos, SMTP/Resend y Meta WhatsApp Cloud API. Webhooks: firma, timestamp, deduplicación, replay seguro y DLQ.
