# Componentes

API: autenticación, autorización, validación, límites y comandos síncronos. Workers: descubrimiento, enriquecimiento, envío, recepción, IA, métricas y reintentos. PostgreSQL: datos tenant y auditoría. Redis: cola, locks y rate limits, no fuente de verdad. Object storage: adjuntos/cotizaciones con metadatos y autorización. Observabilidad: logs estructurados, métricas, trazas y alertas sin secretos/PII innecesaria.
