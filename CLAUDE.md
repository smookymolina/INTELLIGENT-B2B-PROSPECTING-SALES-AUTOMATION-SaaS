# Guía compacta del proyecto

Fuente de verdad: `context/` y `docs/`. Fase 0 está limitada a documentación. Arquitectura objetivo: monolito modular TypeScript, PostgreSQL con RLS, Redis/BullMQ y adaptadores de proveedores. Aislamiento, consentimiento, supresión, trazabilidad y costes de IA son requisitos transversales.

Para cada tarea: leer `CURRENT_STATUS`, documento específico y contratos afectados; entregar cambio acotado, pruebas/evidencia y actualización de log. Ver `AGENTS.md` para reglas operativas.
